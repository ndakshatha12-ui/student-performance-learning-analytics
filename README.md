# Student Performance & Learning Analytics

VEDA Technology Data Science Internship - Major Project

An end-to-end data science workflow on student academic data: cleaning, exploratory analysis, attendance and subject-wise analysis, correlation analysis, visualization, feature engineering, a linear regression prediction model, and model evaluation.

> **Note on the data:** the dataset is **synthetic**, generated by the notebook with a fixed random seed. Relationships such as attendance and study time raising scores were built into the generator, so the results demonstrate the method and are not findings about real students. The generator also injects duplicates, inconsistent text, impossible values and missing values so the cleaning pipeline has real work to do.

```
jupyter notebook student_performance_analytics.ipynb
```
Then use Kernel, Restart and Run All. The CSV files and charts are created next to the notebook.

## Approach

1. **Dataset:** generate 612 synthetic student records with attendance, study hours, previous score, parental support, extra classes and five subject scores.
2. **Cleaning pipeline:** one function that standardizes text, removes duplicates, rescales attendance fractions, turns impossible values into missing values, drops rows missing a subject score, fills remaining gaps, and logs every change. Validation checks confirm the result.
3. **Analysis:** exploratory, attendance, subject-wise and correlation analysis, each with a written interpretation.
4. **Feature engineering:** encoded categories, a log transform of study hours (justified by diminishing returns) and an attendance-shortfall feature (justified by a steeper slope below 65%).
5. **Model:** linear regression predicting average score, trained on 80% of students and tested on the remaining 20%, compared against a baseline.

## Results

| Model | R-squared (test) | MAE (test) | RMSE (test) |
|---|---|---|---|
| Baseline (predict the mean) | -0.002 | 6.64 | - |
| Linear regression, original features | 0.694 | 3.65 | 4.58 |
| Linear regression, engineered features | 0.721 | 3.43 | 4.38 |

- Attendance bands run from an average score of 55.2 (below 60%) to 69.8 (90-100%).
- Maths is the weakest subject (59.9 average) and English the strongest (67.7).
- Previous score, study hours and attendance correlate with average score at 0.54, 0.45 and 0.43.
- The model predicts scores to within about 3.4 points on average, but flags only 7 of 12 genuinely at-risk students in the test set, so it should not be used alone for that purpose.

See `REPORT.md` for the full write-up.

## Limitations

Synthetic data, a linear model, a small test set (114 students), missing values filled before the train/test split, and correlation that does not show cause.
